# Tutorials

Practical, business-friendly walkthroughs showing how to put **auxilia** agents to work in real-world situations — beyond the chat UI.

These are designed to be accessible: you don't need to be a developer to follow along, but your IT or AI engineering team may need to help with the initial setup.

## Available tutorials

- **[Create your first agent](/tutorials/create-an-agent)** — a full walkthrough from naming an agent to chatting with it: identity, MCP servers, tool permissions, and instructions
- **[Trigger agents over HTTP](/tutorials/http-invoke)** — call an **auxilia** agent from any tool that can make a web request, without writing custom code
- **[Trigger agents from Slack](/tutorials/slack)** — give your team a familiar way to talk to agents directly in Slack threads
- **[Embed an agent in a custom UI](/tutorials/embed-custom-ui)** — put an **auxilia** agent inside your customer-support console, back-office dashboard, or Google Sheets add-on
- **[Use auxilia from n8n & Cloud Scheduler](/tutorials/n8n-cloud-scheduler)** — built-in Triggers for schedules, and automation workflows or external schedulers when the plumbing lives elsewhere

## Looking for a full build?

The longer, end-to-end stories — a Google Sheets agent on a service account, slide decks from a skill in GitHub — live in [Case Studies](/case-studies). If you've built something with **auxilia** and want to share the recipe, that's where it goes too.
