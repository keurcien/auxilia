## Write one

Case studies are most useful when they're honest and concrete: the problem in plain terms, the agent's shape (instructions in a few sentences, which MCP servers, skills or sandbox), how it reached users (chat, Slack, embedded, scheduled), what it took to get useful, and the impact if you measured it. Screenshots and snippets of the agent's actual output make them come alive.

To submit one, open a pull request against the docs site: add an MDX file under `docs/content/case-studies/`, start it with the frontmatter below, add an entry to `_meta.js`, and we'll help with editing and framing.

```md
---
title: "How {your team} built {your agent}"
description: "One-sentence hook that shows on the card"
date: "2026-09-23"
author: "Your name"
readingTime: "8 min read"
tags: ["Slack", "HubSpot"]
image: "https://…/cover.png"
---
```
